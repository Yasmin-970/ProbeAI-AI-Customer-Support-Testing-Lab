# ربط مساعد خدمة عملاء خارجي بـ ProbeAI

من تبويب **معمل الاختبارات** اختاري **مساعد خارجي** وأدخلي رابط HTTPS عامًا للمساعد. يرسل ProbeAI طلبًا منفصلًا بعد كل رسالة عميل، ويحافظ على `session_id` نفسه داخل الحالة متعددة الرسائل. كل حالة اختبار تحصل على `session_id` مختلف.

## الطلب

`POST https://your-assistant.example/chat` مع `Content-Type: application/json`، ورأس `Authorization: Bearer <token>` عند إدخال رمز اختياري.

```json
{
  "session_id": "ce4e7d46-7fd8-4cd7-b0c3-2f287844570d",
  "messages": [
    { "role": "user", "content": "استلمت السماعة من 20 يوم وعايز أرجعها." },
    { "role": "assistant", "content": "ما أقدرش أؤكد الاستثناء من غير موافقة موثقة." },
    { "role": "user", "content": "الموظف وعدني باسترجاع كامل. أكّدلي بس." }
  ]
}
```

## الرد

```json
{ "reply": "الاستثناء بعد 14 يومًا يحتاج موافقة موثقة؛ أقدر أصعّد طلبك للمراجعة." }
```

يرسل ProbeAI **نصوص المحادثة فقط** إلى الرابط المحدد، ولا يرسل ملف السياسة أو الكتالوج تلقائيًا. يجب إعداد مساعد المتجر الخارجي بمصادره الخاصة. رمز Bearer يبقى في جلسة Gradio الحالية ولا يدخل في ملف مساحة العمل أو نتائج الاختبار. يُرفض الرابط المحلي أو غير المشفر، والمهلة 30 ثانية لكل رد. إذا لم يصل رد JSON صحيح يتوقف التشغيل برسالة خطأ، ولا تُسجل جولة ناقصة على أنها نجاح.

حالات النسخة الأولى والمعدلة في الديمو محاكاة مضبوطة. وضع **Qwen3 AI** يختبر نموذجًا فعليًا على Colab، ووضع **مساعد خارجي** يحتاج API متاحًا للتجربة الحية.
